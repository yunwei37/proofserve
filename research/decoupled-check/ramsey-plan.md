## Correct producer and exact checker inputs
The whole-library stage copied only selected compiled file types and overlaid
fresh core metadata. It omitted runtime facets such as .ir.sig and shared
libraries. That is unsuitable for executing Meta initializers.
Production now uses the complete original SDK/Mathlib/package paths with an
OAI-only overlay for newly produced Ramsey dependencies. Recompiled
Init/Std/Lean/Lake inputs never replace the distribution's production modules.
Checker inputs are a separate exact source-produced term namespace, with
same-capture common artifacts paired to their recorded compiler CPU.
IR sidecars are preserved for new executable Ramsey helpers.

Four short real controls are required for this actual repair: three previously
failing original files plus an Init iterator import. A failed metadata-only
copy retry is kept; the direct original-package-path retry is separate.
A valid producer setup is not a scientific throughput result or a proof of
the whole library. It prevents repeating the9124configuration-error flood.
